`docs/60-governance/source-register.yaml`; none of these tools is a Python
wheel runtime dependency or a production deployment authorization.

or their transitive dependencies. The optional external-read feature invokes an
exact `mcp==1.28.1` environment installed and managed separately by the user;
`src/dynamic_firm/_mcp_sidecar.py` and `src/dynamic_firm/mcp_connector.py` are
first-party Noruct source and contain no copied SDK source. Those external
packages and servers retain their own licenses and notices.
