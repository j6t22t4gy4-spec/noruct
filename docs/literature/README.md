# AI 에이전트 조직 설계 문헌

Noruct의 설계 배경을 이해하기 위한 한국어 문헌 정리다. 인간 조직설계·조직경제학·전통적 다중에이전트
시스템·LLM 멀티에이전트 연구를 연결한다. 제품 규범이나 현재 구현 설명을 대신하지 않는다.

1. [AI 에이전트 조직의 계산적 거버넌스](organization_governance_theory.md)
   — 조직을 과업·정보·권한·오류·검증·학습의 구조로 살펴보고, 인간과 에이전트가 어떻게 소통하고 통제할지 정리한다.

## 연구를 이어 읽는 순서

1. 위 원고에서 이론·권한·인간 통제의 범위를 읽는다. v0.9 초안은 기존 저자 관점을 보존하면서 용어·논증 경계와 가설→실험의 연결을 보강한다.
2. [분업의 한계가치와 최소 충분 인계: 검증 프로토콜](organization_value_experiment.md)에서 세 가설, MAO-ARAG와의 비교, 통제군과 반증조건을 확인한다.
3. [실험 기록 template](organization_experiment_record.template.json)으로 후보 집합·실제 노출·품질·전체 비용과 누락을 남긴다.

새 프로토콜은 **미실행 초안**이다. 표본수·주 지표·실험 예산이 동결되기 전에는 사전 등록된 실험으로 부르지 않는다.
private 개발 기록과 제품 구현 상태는 이 공개 연구 디렉터리의 성능 증거가 아니다.

## 핵심 논증을 빠르게 확인하려면

- 원고 §1.4–1.6: 주장 연결과 용어의 범위
- §6.1·8.8: 실행 방식·조직·제도의 구분과 보고서 작성 예시
- §13.1·14.7: 미위임과 금지의 구분, 필수 승인과 재량적 상향의 순서
- §18.6·18.10: 명제별 대조실험과 주장을 약화하는 관찰

## 읽을 때 참고할 점

- 문헌의 관찰, 이 문서의 해석, 아직 검증이 필요한 가설을 구분한다.
- 수식과 예시는 설계 관계를 설명하는 도구이며, 검증된 성능 법칙이 아니다.
- 인용과 연구 수치는 별도 독립 검증을 마친 제품 성능 근거가 아니다.
