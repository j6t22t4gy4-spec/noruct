# AI 에이전트 조직 설계 문헌

Noruct의 설계 배경을 이해하기 위한 한국어 문헌 정리다. 인간 조직설계·조직경제학·전통적 다중에이전트
시스템·LLM 멀티에이전트 연구를 연결한다. 제품 규범이나 현재 구현 설명을 대신하지 않는다.

1. [AI 에이전트 조직의 계산적 거버넌스](organization_governance_theory.md)
   — 조직을 과업·정보·권한·오류·검증·학습의 구조로 살펴보고, 인간과 에이전트가 어떻게 소통하고 통제할지 정리한다.

## 읽을 때 참고할 점

- 문헌의 관찰, 이 문서의 해석, 아직 검증이 필요한 가설을 구분한다.
- 수식과 예시는 설계 관계를 설명하는 도구이며, 검증된 성능 법칙이 아니다.
- 인용과 연구 수치는 별도 독립 검증을 마친 제품 성능 근거가 아니다.
