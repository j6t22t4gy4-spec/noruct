# Noruct

Noruct는 사용자가 하나의 회사 인터페이스에 목표를 전달하면, 필요한 실행 능력을 선택·조직하고 결과를 통합해
보고하는 AI agent platform입니다. 이 제품의 핵심 패러다임은 **Dynamic Firm Runtime**입니다.

사용자는 agent 수, 역할, 병렬화, workflow를 직접 설계할 필요가 없습니다. 기본적으로 회사에 목표를 전달하고,
중요한 권한·비용·외부 행동의 경계에서만 판단합니다.

## 핵심 원칙

- 한 Employee로 충분하면 팀을 만들지 않습니다.
- 병렬 실행은 기능 과시가 아니라 실제 의존관계와 capability 차이의 결과입니다.
- 역할 이름만 다른 clone을 전문 조직으로 부르지 않습니다.
- 지식, 사용자 의도, 실행 권한을 서로 다른 상태로 분리합니다.
- 고비용·비가역·외부 약속은 사용자 권한 없이 자동 실행하지 않습니다.
- 검증된 변화만 Employee Skill, workflow 또는 roster에 남깁니다.
