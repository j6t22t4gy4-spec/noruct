# Noruct public documentation

**English is the canonical version of this documentation.**

- [Read the English canonical documentation](en/README.md)
- [한국어 번역 문서 읽기](ko/README.md)

The two editions share the same conceptual structure. When wording differs, the English edition is authoritative.
The literature directory preserves original-language source papers and is not part of the canonical product contract.

The public Core is a local-first MIT-licensed monorepo. Noruct-operated Shared Evolution and Network server
infrastructure remains a separate private hosted-service boundary; user-configured providers, MCP/web transports, and
client-side signed-artifact safety contracts remain part of the public Core. Vendored and third-party material retains
the license and notice identified in its source directory and `THIRD_PARTY_NOTICES.md`.
